# CIA II – Retail Business Data Analysis

## CHRIST (Deemed to be University) – BBA

This repository contains the complete Jupyter Notebook submission for the CIA II group assignment on Business Data Analysis and Visualization using Python.

### Tools
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / JupyterLab

### Project
**Retail Sales and Profitability Analysis**

The project demonstrates an end-to-end business analytics workflow:
1. Data inspection
2. Data cleaning and transformation
3. Numerical analysis using NumPy
4. Business analysis using Pandas
5. Visualization using Matplotlib and Seaborn
6. Executive dashboard/reporting
7. Business insights and recommendations

### Dataset
The retail dataset is synthetic and created for academic demonstration. It is not represented as proprietary company data.

### Running the Notebook
Open `Retail_Business_Analysis.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab and run all cells from top to bottom.
